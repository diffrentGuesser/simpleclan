SimpleClan

Clans for Fabric servers. Players get a colored [Clan] tag and their own clan chat, and you decide who shows up on their locator bar.

What it adds

Players create clans with /clan create <name> <color>, invite friends, and talk in a chat only their clan can read. Every member gets the clan's name as a colored prefix in chat, in the tab list and above their head.

The prefix uses Minecraft's own scoreboard teams, so it works on unmodified clients. Your players don't install anything.

For players

Clan owners invite people with /clan invite, or players ask to join with /clan join and the owner accepts or denies. Owners can kick members, hand the clan to someone else, or disband it. Clan names can be up to 16 characters, in any of Minecraft's 16 text colors.

For you

Operators can disband any clan, invite or kick players, and transfer ownership with /clan op. You also choose who appears on each player's locator bar, and whether the clan tag goes before or after player names: [Wolves] Steve or Steve [Wolves].

Locator bar

Since 1.21.6 the locator bar above the hotbar shows a dot for every nearby player. SimpleClan lets you limit that: everyone (vanilla), only players in your own clan, or nobody. Players without a clan see nobody in clan mode.

  • [Wolves] Alex same clan as Steve
  • [Ravens] Mira other clan
  • Kai no clan

This is Steve's view. Steve is in [Wolves].

Set the mode in config/simple-clan.json, or change it in game with /clan locatorbar <everyone|clan|nobody> (operator level 4). The command takes effect immediately and saves the config.

{
  "locatorBar": "clan",
  "tagPosition": "left"
}

tagPosition is left (default) or right. You can also switch it in game with /clan tagposition <left|right>.

Commands

All SimpleClan commands
CommandWhat it does
Everyone
/clan create <name> <color>Create a clan. Color is a Minecraft color like red, blue or gold.
/clan accept · /clan denyAnswer an invite.
/clan join <clan>Ask to join a clan. The owner gets a message.
/clan message <text>Send a message only your clan sees.
/clan list · /clan list allShow your clan's members, or every clan.
/clan leaveLeave your clan.
/clan refreshRe-apply your clan prefix.
Clan owner
/clan invite <player>Invite an online player.
/clan accept <player> · /clan deny <player>Answer a join request. The player has to be online.
/clan kick <player>Remove a member.
/clan transfer <player>Make another member the owner.
/clan disbandDelete the clan.
Operators (level 4)
/clan op <clan> disbandDelete any clan.
/clan op <clan> invite|kick|transfer <player>Manage any clan's members and owner.
/clan locatorbar <mode>Show or set the locator bar mode.
/clan tagposition <left|right>Show the clan tag before or after player names.

Install

  1. Make sure the server runs Fabric Loader for Minecraft 26.1, 26.1.1, 26.1.2, 26.2 or 26.3.
  2. Put Fabric API and simple-clan-1.2.2.jar in the server's mods folder.
  3. Restart the server. Players can use /clan right away.

Files it uses

config/simple-clan.json
Locator bar mode and tag position. Created on first start.
clan_data/
Clans, invites and join requests, in the server folder.
Scoreboard teams clan_<name>
One per clan, for the name prefix.

Clan data is written when the server stops. If the server crashes, changes since the last restart are lost.
